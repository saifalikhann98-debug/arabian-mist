# Arabian Mist Perfume Website

A luxury UAE perfume brand website with an editorial ecommerce layout, Arabian Mist branding, animated sections, a product detail area, interactive fragrance accords, quantity controls, and add-to-bag feedback.

## Run Locally

```bash
npm run dev
```

Then open:

```text
http://localhost:4173/index.html
```

## Project Files

- `index.html` - page structure and product content
- `styles.css` - luxury visual design, responsive layout, animations
- `script.js` - menu, reveal effects, product detail interactions, cart toast
- `assets/` - generated perfume imagery and the Arabian Mist SVG logo

## Notes

This project is dependency-free. The `npm` scripts use Python's built-in static file server, so there is no install step required.
